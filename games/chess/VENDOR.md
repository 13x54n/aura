# Chess mini-app (`games/chess`)

- Rules engine: [chess.js](https://github.com/jhlywa/chess.js) v0.13.4 (BSD-2) in `vendor/chess.min.js`
- UI pattern adapted from [GizzZmo/Chession](https://github.com/GizzZmo/Chession) (MIT) — see LICENSE
- Free Play: you = White, random legal moves for Black
- Pack: `node scripts/pack-chess.mjs` → `mobile/src/runtime/chessBundle.ts`
