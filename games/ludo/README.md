# Aura Ludo (mini-app)

Playable Free Play Ludo — HTML5 Canvas. Aura’s store only catalogs and launches this package in a WebView.

## Play locally
Open `index.html` in a browser, or:

```bash
node ../../scripts/pack-ludo.mjs   # from repo root: node scripts/pack-ludo.mjs
```

## Controls
- **Roll** — your turn (Red)
- Tap a **highlighted** piece to move
- Six to leave the yard; exact finish; bots play the other colors
- **Close** — calls Host `nav.close` when mounted in Aura
